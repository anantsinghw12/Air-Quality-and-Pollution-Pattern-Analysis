# ESP32 with 3 Potentiometers and I2C LCD

This is an IoT/Embedded simulation project built using **ESP32**, **3 Potentiometers**, and an **I2C 16x2 LCD Display**, simulated on Wokwi.

## 🔌 Circuit Connections
| Component | ESP32 Pin |
| :--- | :--- |
| LCD SDA | GPIO 21 |
| LCD SCL | GPIO 22 |
| Pot 1 (A) | GPIO 35 |
| Pot 2 (B) | GPIO 34 |
| Pot 3 (C) | GPIO 32 |
